# GSB 시즌 생산관리 관제탑 (웹사이트)

구글 시트에 입력된 시즌 생산 정보를 제품별로 보기 쉽게 보여주는 읽기 전용 사이트입니다. 이 저장소에는 데이터가 없습니다. 사이트를 연 사람이 회사 구글 계정으로 로그인하면, 그 사람에게 공유된 시트만 읽어서 보여줍니다.

## 파일
- index.html, style.css, app.js: 사이트 화면
- config.js: 구글 로그인 클라이언트 ID와 시즌 시트 ID를 적는 곳 (이 파일만 수정)

## 연결 순서
1. 시즌 시트를 GSB 공유 드라이브에 구글 시트로 올립니다. 탭 이름과 3행 열 제목은 바꾸지 않습니다.
2. 원가와 판가는 별도 구글 시트(탭 이름: 원가판가)로 두고 권한 있는 사람에게만 공유합니다.
3. 구글 클라우드 콘솔에서 Google Sheets API를 켜고, OAuth 동의 화면을 내부로 설정한 뒤, 웹 애플리케이션용 OAuth 클라이언트 ID를 만듭니다. 승인된 JavaScript 원본에 사이트 주소를 넣습니다.
4. config.js에 클라이언트 ID와 시트 ID를 넣습니다.
5. Settings, Pages에서 배포합니다. 무료 플랜은 Public 저장소만 Pages 배포가 됩니다.

## 권한
- 시트 공유 권한이 없는 계정은 사이트를 열어도 데이터가 보이지 않습니다.
- 원가 시트 권한이 없는 계정에는 원가와 판가가 표시되지 않습니다.
