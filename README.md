# 리넥츠 시즌 관제탑 (웹사이트)

팀이 보는 **보기 전용** 화면입니다. 원본은 공유 드라이브의 구글 시트 「리넥츠 시즌 진행현황」이고, 이 저장소에는 그 사본(암호화)과 화면 코드만 있습니다.

## 구조
```
index.html, app.js, style.css   화면 (GitHub Pages로 그대로 배포)
data/manifest.json              시즌 목록, 최신화 시각, 암호 확인값
data/seasons/{시즌}.json         시즌별 데이터 (AES-GCM 암호화). 시즌이 늘면 파일이 하나씩 쌓임
tools/build_data.py             시트(xlsx 내보내기) → data/ 생성 스크립트
```
- 화면은 최신 시즌이 위, 예전 시즌이 아래로 이어집니다. 위쪽 시즌 버튼으로 바로 이동.
- 검색: 품번, 컬러코드, 품번_컬러, 아이템명, 기획명, 단계, 최근 내용, 메모. 띄어쓰기로 여러 단어를 넣으면 모두 포함된 건만 나옵니다. `/` 키로 검색창 이동, `Esc`로 지우기. 검색 주소(#q=...)를 그대로 공유할 수 있습니다.
- 필터: 구분(신규/리오더/드랍), 단계(눌러서 끄고 켜기), 보기(보드/목록).

## 비밀번호
- 페이지와 데이터 파일은 공개 주소에 있지만, 데이터는 팀 공용 비밀번호 없이는 읽을 수 없습니다.
- 비밀번호는 이 저장소·위키·대화에 적지 않습니다. 담당자 PC의 `C:\Users\us\.gsb\site.json`(`{"sitePassword": "..."}`)에만 둡니다.
- 원가·판가는 데이터에 넣지 않습니다.

## 최신화 절차 (Claude가 수행)
1. 담당자가 시트를 고친 뒤 Claude 프로젝트에서 "최신화"를 요청한다.
2. Claude가 구글 드라이브에서 진행현황 시트를 xlsx로 내려받는다.
3. `python3 tools/build_data.py --xlsx 진행현황.xlsx --out data --password-file site.json --sheet-url <시트 주소>`
   - 시트에 있는 시즌만 다시 만들고, 시트에서 빠진 예전 시즌 파일은 그대로 둔다.
   - 비밀번호가 기존과 다르면 멈춘다(실수로 다른 비밀번호로 덮어쓰기 방지).
4. 바뀐 `data/` 파일을 GitHub에 올린다(커밋 메시지: `data: 최신화 YYYY-MM-DD HH:MM`).
5. 1~2분 뒤 사이트에 반영된다. 화면 오른쪽 위 "최신화" 시각으로 확인.

비밀번호 바꾸기: `SITE_OLD_PASSWORD=옛것 python3 tools/build_data.py ... --password-file 새것.json --new-password`

## 배포
Settings → Pages → Branch `main` / `/ (root)`. 비공개 저장소에서 Pages를 쓰려면 GitHub 유료 플랜이 필요합니다(무료면 저장소를 공개로 두어도 데이터는 암호화되어 있음).
